# DESIGN SYSTEM — נגזר מ-WP-D1

**עודכן:** 2026-08-29 · **מקור:** מוקאפים `docs/mockups/wp-d1-batch{1,2,3}.html` (אושרו כיוונית ע"י הלקוח — עיצוב; תוכן יעודכן בהמשך).
שפה ויזואלית: **Calm Wellness** (ADR-012). Light בלבד. עברית RTL. Desktop-first.

> **פלטה זמנית** — נגזרה ממראה האינסטגרם של נופר (ירוק מרווה + רוז' רך). תינעל ב-ADR נפרד עם קבלת לוגו/צבעים רשמיים.

## 2. טיפוגרפיה

| תפקיד | פונט | משקלים |
|-------|------|--------|
| כותרות, שמות מטופלים, מספרי מדד גדולים | **Frank Ruhl Libre** (סריף עברי קלאסי, חם) | 500 / 700 |
| גוף, UI, טבלאות, כפתורים, שדות | **Assistant** (סאנס עברי, קריא מאוד) | 400 / 500 / 600 / 700 |

- Google Fonts (מותר ב-CSP של Artifacts; במימוש — `next/font`).
- מספרים בטבלאות ובמדדים: `font-variant-numeric: tabular-nums`.
- כותרות: `text-wrap: balance`.
- סקאלה (px): 30/25 כותרות עמוד · 21–23 כותרות מסמך · 15 גוף · 13.5 UI · 12.5 משני · 11–11.5 תוויות.
- תוויות uppercase-קטנות: `letter-spacing: .04–.08em`.

## 3. פריסה, מרווח, צורה

- **מרווח:** סולם 4 / 8 / 12 / 16 / 24 / 32 / 40. פריסה עם `flex`/`grid` + `gap` (לא margin פר-אלמנט).
- **רדיוסים:** כרטיס `16px` · פקד/כפתור `10px` · pill/chip מלא · avatar עיגול.
- **צל:** רך ומדוד בלבד — `0 1px 2px rgba(44,54,48,.04), 0 10px 28px -14px rgba(44,54,48,.14)`.
- **רוחב תוכן:** מטפל עד ~1200px · מטופל עד ~880px (רגוע יותר) · שאלון/טופס עד ~620px.
- **RTL:** `dir="rtl"` בשורש; שימוש ב-logical properties (`padding-inline-start`, `inset-inline-start`, `margin-inline-start`).
- **תנועה:** `transition` 120–180ms על hover/מעבר; `@media (prefers-reduced-motion: reduce)` מבטל הכל.
- **focus:** `outline: 2px solid var(--sage-deep); outline-offset: 2px` — תמיד נראה.

## 5. מלאי רכיבי יסוד (מהמוקאפים → WP-01)

**בסיס:** Button (`primary` / default / `ghost` / `sm`) · Input / Textarea / Select · Checkbox · Toggle-chip · Segmented control · Search field · Pill (סטטוס) · Chip (סוג טיפול / קטגוריה) · Avatar (30/36/56/64) · Badge · Icon set (stroke 1.6, linecap round, 24 viewBox) · Progress bar · Card (+ card-head/body).

**מורכבים:** טבלת דאטה עם שורה לחיצה · Stepper דביק (אנכי, מתעדכן בגלילה) · Timeline אנכי עם node מסווג לפי סוג אירוע · Repeatable-rows (תוספים/משימות — עריכת inline) · Editable bullet list · Version-history item · שדה מדד עם תג «מוצג בגרף» · הערה נעולה «גלוי למטפל בלבד» · Hero "פגישה הבאה" · Attention list (דורש התייחסות).

**מצבים (חובה לכל מסך):** ריק (מסביר מה עושים הלאה) · טעינה (skeleton) · שגיאה (מה קרה + איך לתקן).

## 6. נגישות ותוכן

- ניגודיות: כל טקסט עומד ב-WCAG AA. לבדוק במיוחד `--ink-faint` על `--surface` לגדלים קטנים.
- כל פקד אינטראקטיבי: תווית, מצב focus נראה, יעד מגע ≥ 36px.
- טקסטים למשתמש בעברית, מרוכזים ב-`lib/strings.ts` (מפתח → מחרוזת).
- קול הכתיבה: פעיל, מדויק, מעודד בצד המטופל ("את בכיוון מצוין"); ענייני ורזה בצד המטפל.
- כפתור אומר מה יקרה ("פרסום גרסה 4"), טוסט מאשר מה קרה ("גרסה 4 פורסמה").
